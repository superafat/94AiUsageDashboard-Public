# 額度通知（v0.1.4）

在「設定」可以為每個 AI 來源分別開啟「每耗用 10% 通知」及「額度重置通知」，兩者預設都關閉。來源必須有可信的百分比或總額度上限，才會產生耗用提醒；純餘額或不知道上限的資料不會被猜成百分比。首次啟用只建立起始紀錄，不補發過去的門檻。

## 開始使用

先讓 Mac Companion 使用目前版本並正常同步。同步程式會在該使用者的 Firebase 發布 Mac 的公開推播識別資訊，私密簽署金鑰留在本機。接著在手機或桌面開啟儀表板的「設定」，依手機版本完成平台設定與啟用。有多台 Mac 時，選擇負責發送的那一台，避免同一手機重複接收。

### iPhone／iPad 設定步驟

1. 使用 **Safari** 瀏覽器開啟儀表板網址。
2. 點擊瀏覽器底部的「分享」按鈕，選擇「**加入主畫面**」。
3. 從主畫面上的應用程式圖示開啟。
4. 登入帳號後前往「設定」頁面。
5. 點擊「**啟用推播通知**」。
6. 在系統權限提示中選擇「**允許**」。
7. 於下方各 AI 服務開啟「每耗用10%通知」或「額度重置通知」。
8. 點擊「**發送測試推播**」進行測試。

> **注意事項**：
> - iPhone／iPad 必須透過主畫面 PWA 才能支援 Web Push 推播通知。
> - 專注模式、靜音或系統通知設定可能隱藏通知提示。
> - 測試請求已保存或推播服務已受理，不代表手機已實際顯示通知。

### Android 設定步驟

1. 使用 **Chrome** 瀏覽器開啟儀表板網址。
2. 點擊瀏覽器選單「**安裝應用程式**」或「**加到主畫面**」。
3. 從主畫面或應用程式清單開啟已安裝的 PWA。
4. 登入帳號後前往「設定」頁面。
5. 點擊「**啟用推播通知**」。
6. 在系統權限提示中選擇「**允許**」通知權限。
7. 於下方各 AI 服務開啟所需的通知開關。
8. 點擊「**發送測試推播**」進行測試。

> **注意事項**：
> - 建議使用 Chrome 瀏覽器以獲得最佳 Web Push 相容性。
> - Android 系統電池最佳化或背景限制可能延遲通知送達。
> - 推播服務已受理不等於裝置已實際顯示通知。

## 常見問題與排查 (Troubleshooting)

- **找不到「啟用推播通知」按鈕**：請確認是否已加到主畫面並開啟，或確認瀏覽器是否支援 Web Push。
- **Mac Companion 離線**：需有最近 10 分鐘內回報的 Mac OpenUsage 執行推播發送。請先開啟並連線 Mac Companion。
- **測試推播成功，但尚未收到自動通知**：正式來源由 Mac 同步程式約每 5 分鐘檢查一次額度變動。若無額度變化或門檻未到則不會發送通知。
- **通知權限被拒絕或封鎖**：請至系統設定或網址列解除通知封鎖，重新整理頁面後即可再次啟用。

## 判斷方式

耗用通知採固定 10 個百分點門檻，例如剩餘 81% 降到 69%，只合併通知一次，不連續轟炸。短時間資料更正不會重新補發舊門檻。重置通知須觀察到新的來源週期與明確額度恢復，倒數歸零、零星回補或舊資料重送都不算確認重置。

同一來源的不同額度類型或週期（例如 5 小時額度與每週額度）各自獨立維護通知，不會互相覆蓋或坍縮合併。通知失敗不會阻斷原本額度與歷史同步。每個瀏覽器的傳送接受紀錄分開保存，另一支手機失敗不應讓成功的手機一直重複接收。

## 隱私、通知格式與限制

鎖定畫面推播通知會明確顯示 AI 服務來源與可信的額度類別（例如 `Codex · 5 小時額度` 或 `Claude Code · Sonnet 每週`），並以正體中文標明當前的耗用與剩餘百分比（例如 `已達 35% 耗用，剩餘 65%`），絕不臆測未經證實的模型名稱。若來源無法可靠辨識模型名稱，則僅顯示來源與額度類別，不猜測型號。重置通知會標明相同的服務與額度名稱（例如 `Codex · 5 小時額度已重置`，內文 `額度已確認恢復，點此查看。`）。測試推播則維持通用測試內容。

鎖定畫面嚴格落實隱私隔離，絕不顯示帳號識別、電子郵件、金額、Token、憑證或對話內容。點擊只開啟同一個儀表板，內容仍須登入查看。訂閱資料只存於自己的 Firebase 帳號，推播服務接受請求不代表裝置已顯示。

「停用推播通知」會先撤銷這個瀏覽器的本機訂閱識別；登出也會撤銷，避免離線登出後接收上一個帳號的訊息。個別來源通知開關於 Mac 下次成功讀取設定後生效；已被外部推播服務接受的通知仍受短期限與裝置狀態影響。關閉來源不會刪除歷史、登出 AI 工具或修改 OpenUsage 自己的通知設定。

此功能不會自動使用 Codex 重置券、購買額度、啟用付費 GitHub 功能或建立新的雲端排程服務。瀏覽器通知權限由使用者親自允許。App Store／Google Play 原生 App 為另一個發布項目，目前尚未發布。

來源規格：WebKit Home Screen Web Push、MDN Push API 與 IndexedDB 交易規格。裝置實際通知顯示需另做實機驗收，單元測試或瀏覽器測試不能替代。
